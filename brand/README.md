# Open Everywhere brand assets

The project mark is a pigeon that looks over a ledge. These files are the project's identity: the
README, the npm pages, the GitHub organisation and the website use them.

With no `identity.name` set, your agent presents as the project, and this mark is its default
avatar. Set `identity.name` and choose your own icon to change it.

## Two versions

- **Small** (`mark*`): a big head. Use it at 64 px and below: app icons, avatars, favicons.
- **Big** (`mark-big*`): a small head on shoulders. Use it for the website, hero images and cards.

## Which file goes where

| Use | File |
| --- | --- |
| Slack, Teams or Discord app icon, GitHub or npm avatar | `png/mark-square-1024.png` |
| GitHub repository social preview (1280×640) | `png/github-social-preview.png` |
| Open Graph or X card (1200×630) | `png/social-card.png` |
| Website favicon | `svg/favicon.svg`, with `favicon.ico` and `png/apple-touch-icon.png` as fallbacks |
| Website header | `svg/lockup-ink.svg` on light backgrounds, `svg/lockup-paper.svg` on dark |
| Website hero, print | `svg/mark-big.svg`, or one of its `-square` and one-colour versions |
| One colour | `svg/mark-mono-ink.svg`, `svg/mark-mono-paper.svg`, and the `-big-` versions |
| Wordmark alone | `svg/wordmark-ink.svg`, `svg/wordmark-paper.svg` |

The `-level` files are the alternative mark, with the head level instead of cocked.

Colours: ink `#1a1a1a`, paper `#f5efe6`, eyes `#e8802c`, beak of the big version `#4a4744`.

identify this project; do not use them in a way that suggests a fork or another product is this
project.
