# Support

Thanks for using Open Everywhere. Here's where to go for help.

## I have a question / need help setting up

- **Read the docs first.** Start with the [README](./README.md), the
  [setup runbook](./docs/deploy/setup-runbook.md), and the [surface guides](./docs/deploy/surfaces/) for your platform
  (Slack / Teams / Discord / Linear).
- **Search existing issues and discussions** — your question may already be answered.
- **Open a [GitHub Discussion](../../discussions)** for questions, ideas, and "how do I…" — not the issue
  tracker. (Maintainers: enable Discussions under repo Settings.)

## I found a bug

Open a [bug report](../../issues/new/choose). Include your deploy target (Vercel / self-host), the surface,
the model/provider, and the smallest reproduction you can.

## I want to request a feature

Open a [feature request](../../issues/new/choose). Describe the problem you're trying to solve, not just the
solution — it helps us find the best fit.

## I found a security vulnerability

**Do not open a public issue.** Follow the [Security Policy](./SECURITY.md) — use GitHub's private
vulnerability reporting.

## I want to contribute

See [CONTRIBUTING.md](./CONTRIBUTING.md). Contributions are accepted under the Developer Certificate of
Origin (`git commit -s`).

> This is a community open-source project maintained on a best-effort basis. There is no commercial support
> or SLA.
